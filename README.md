# Лабораторная работа №1

## Тема
Транспортные средства

## Описание
Консольная программа для управления транспортными средствами.

## Возможности
- добавление автомобиля;
- добавление грузовика;
- добавление мотоцикла;
- просмотр списка транспорта;
- изменение транспорта;
- удаление транспорта;
- обработка некорректного ввода.

## Структура проекта
- data_layer.py - классы транспортных средств.
- repository_layer.py - хранение транспорта и операции CRUD.
- service_layer.py - логика работы с транспортом.
- main.py - консольный интерфейс и запуск программы.

## Запуск
Программа запускается, запустив файл main.py
