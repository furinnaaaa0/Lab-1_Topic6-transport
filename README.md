# Лабораторная работа №1

## Тема

Транспортные средства и гаражи

## Описание

Консольная программа для управления транспортными средствами и гаражами.

Программа позволяет работать с транспортными средствами, размещать их в гаражах, сохранять данные в файл и загружать их при следующем запуске.

## Возможности

- добавление автомобиля;
- добавление грузовика;
- добавление мотоцикла;
- просмотр списка транспорта;
- изменение транспорта;
- удаление транспорта;
- добавление гаража;
- просмотр списка гаражей;
- изменение гаража;
- удаление гаража;
- размещение транспорта в гараже;
- удаление транспорта из гаража;
- проверка вместимости гаража;
- автоматическое освобождение транспорта при удалении гаража;
- сохранение данных в файл;
- загрузка данных из файла;
- тестирование основной логики программы;
- обработка некорректного ввода.

## Структура проекта

- data_layer.py - классы транспортных средств и гаражей.
- repository_layer.py - хранение объектов и операции CRUD.
- service_layer.py - логика работы с транспортом и гаражами.
- main.py - консольный интерфейс и запуск программы.
- tests - тесты основной логики программы.

## Запуск

Программа запускается, запустив файл main.py
